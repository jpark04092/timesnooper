# 🛡️ Timesnooper Built APK Releases

GitHub Actions 및 로컬 빌드에 의해 생성된 최신 안드로이드 설치/업데이트용 APK 폴더입니다.

- **최신 디버그 APK**: `timesnooper-debug.apk` (또는 `app-debug.apk`)
- **최신 릴리즈 APK**: `timesnooper-release.apk`
- **버전**: v1.0.1 (versionCode: 2)
- **서명 상태**: 프로젝트 고정 Keystore (`timesnooper.keystore`) 서명 완료

---

## 📱 다운로드 및 기기 설치/업데이트 방법

### 1. 첫 설치 (고정 서명 키 최초 전환 시)
> 과거 임시 키로 빌드된 구버전 앱이 이미 설치되어 있다면, 고정 키로 전환하기 위해 **이번 1회만 기존 앱을 삭제 후 신규 APK를 설치**해주세요.

1. GitHub 저장소의 `release/timesnooper-debug.apk`를 기기(스마트폰/태블릿)로 다운로드합니다.
2. 다운로드 폴더에서 APK를 터치하여 설치합니다.
3. 앱을 열어 관리자 비밀번호, 발송 계정(Gmail 앱 비밀번호), 발송 시각 등을 설정하고 **[설정 저장]**을 누릅니다.
4. (선택) **[설정 백업 (복사)]** 버튼을 눌러 메모장에 백업해두실 수 있습니다.

---

### 2. 이후 업데이트 방법 (기존 앱 삭제 절대 불필요!)
> 이제부터는 영구적으로 동일한 고정 Keystore로 서명되므로, **앱을 지우지 않고 바로 덮어쓰기 업데이트**가 가능합니다.
> **발송용 계정 키, 이메일 주소, 알람 시각, 관리자 PIN, Device Owner 권한이 100% 그대로 유지**됩니다.

1. 새로 빌드된 `timesnooper-debug.apk`를 기기로 다운로드합니다.
2. APK 파일을 터치하면 안드로이드 시스템이 **"기존 앱의 업데이트를 설치하시겠습니까? 기존 데이터는 손실되지 않습니다."** 안내를 띄웁니다.
3. **[업데이트/설치]**를 누르면 1초 만에 최신 버전으로 교체 완료됩니다.
